# Support

Batch Sequence File Renamer is published as a polished showcase and download page.

## Scope

- `v1.1.0` is distributed as a standalone binary release
- `v1.1.0` source code is not public
- `v1.0.0` source is provided for historical and transparency purposes

## Support Policy

- This repository is not positioned as an open public development project
- Feature requests, source requests for `v1.1.0`, and roadmap requests may not receive a response
- Security-sensitive reports should be shared privately with the maintainer rather than posted publicly

## Issues

GitHub Issues may be left disabled if the repository is being used strictly as a showcase and release page.
