# Changelog

All notable public releases for Batch Sequence File Renamer are documented here.

## [v1.1.0] - 2026-08-21

Current public release distributed as a standalone Windows executable.

### Changed

- Repositioned the project as a download-first public release
- Promoted `v1.1.0` as the current release on GitHub
- Kept `v1.1` source private while publishing release notes and binary distribution

### Product Improvements

- Expanded sequence generation capabilities beyond the original `v1.0.0` workflow
- Improved preset coverage and practical file naming patterns
- Added stronger production-oriented workflow support, including rollback-focused usage

## [v1.0.0] - 2026-08-21

Earlier open-source version published for transparency and historical reference.

### Included

- Public AutoHotkey source snapshot
- Standalone AutoHotkey script entrypoint
- Modular library structure for validation, Explorer capture, transactions, logging, GUI, and rename logic
