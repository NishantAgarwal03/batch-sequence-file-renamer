# Batch Sequence File Renamer

Batch Sequence File Renamer is a Windows utility for renaming files and folders in a user-defined order with sequence tokens, pattern-based output, and rollback support.

This repository is intentionally selective:

- The current release is `v1.1.0`, distributed as a standalone Windows executable through GitHub Releases.
- The earlier open-source version, `v1.0.0`, is included in [`source-v1.0/`](./source-v1.0).
- `v1.1` source code is not published in this repository.

## Download

Download the latest Windows executable from the repository's **Releases** page:

- Release: `v1.1.0`
- Asset: `Batch Sequence File Renamer v1.1.exe`
- Release date: August 21, 2026

## Highlights

- Sequential renaming in explicit user-selected order
- Pattern-based naming with tokens for sequence, filename parts, and timestamps
- Multi-step sequence generation for structured file batches
- Batch undo workflow for rollback after rename operations
- Windows-first workflow designed around Explorer selection and drag-and-drop
